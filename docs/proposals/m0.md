## Files

Config
- `package.json` — scripts `dev`, `build`, `start`, `lint` (`eslint .`), `typecheck` (`tsc --noEmit`), `test` (`vitest run`).
- `package-lock.json`, `.gitignore`.
- `tsconfig.json` — `strict`, `erasableSyntaxOnly`, `@/*` → `src/*`.
- `next.config.ts`, `postcss.config.mjs`, `vitest.config.mts`.
- `eslint.config.mjs` — flat config with `eslint-config-next` (`core-web-vitals` + `typescript`), plus a `src/domain` boundary rule:
  - `no-restricted-imports`: `next`, `next/*`, `react`, `react/*`, `react-dom`, `react-dom/*`, `postgres`, `@supabase/*`, and Node I/O modules with and without the `node:` prefix (`fs`, `fs/promises`, `net`, `http`, `https`, `http2`, `dns`, `tls`, `dgram`, `child_process`, `worker_threads`, `cluster`).
  - PROPOSED: `no-restricted-globals` for `fetch`, `XMLHttpRequest`, `WebSocket`.

App
- `src/app/layout.tsx` — `lang="hi"`, system font stack (Geist dropped: no Devanagari and it needs Google Fonts at build time; the Devanagari subset is M13).
- `src/app/page.tsx` — "PurohitDesk" / "पुरोहित डेस्क", text ≥ 16 px.
- `src/app/globals.css` — Tailwind v4; PROPOSED placeholder theme colour saffron `#C2410C` as a CSS variable.
- `src/app/api/v1/healthz/route.ts` — `GET` → `200 {"status":"ok","commit": VERCEL_GIT_COMMIT_SHA || "unknown"}`, `Cache-Control: no-store`, `dynamic = "force-dynamic"`; plain `Response`, no Next runtime import.
