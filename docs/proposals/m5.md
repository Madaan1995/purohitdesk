## 1. Tables (columns AUTO-DECIDED — needs founder review)

### `app.samagri_templates` (tenant)
`id`, `org_id`, `offering_id` NOT NULL, `version`, `created_at`, `updated_at`. Composite FK `(offering_id, org_id) →
offerings (id, org_id)` (spec §04 §4); UNIQUE `(org_id, offering_id)` — **one template per offering** ("Template per
offering", spec §01 §3); UNIQUE `(id, org_id)`.

### `app.samagri_template_items` (tenant)
`id`, `org_id`, `template_id`, `position` int ≥ 1, `name` text 1–120, `quantity` text NULL 1–60 (e.g. "1 kg",
"5 पान"), `provided_by` CHECK in (`FAMILY`, `PRIEST`). Composite FK `(template_id, org_id) → samagri_templates (id,
org_id) ON DELETE CASCADE` (spec §04 §4); UNIQUE `(template_id, position)`.
- **AUTO-DECIDED:** `quantity` as free text (priests write "1 kg", "21", "थोड़ा").
- Items are replaced as a whole on every save (delete + insert in the same transaction); the template's version
  bumps on every save.

### `app.audit_log` (tenant, append-only)
`id` bigint identity PK, `org_id`, `actor_user_id` NULL FK app_users, `action` CHECK in (`ORG_UPDATED`,
`BLOCK_CREATED`, `CUSTOMER_ERASED`, `EXPORT`) (spec §11 §5), `target_id` uuid NULL, `data` jsonb NOT NULL DEFAULT
`{}` (ids, codes and field names only — never free text, golden rule 8), `created_at`. Index `(org_id, created_at)`.
Guard trigger `tg_audit_guard`: UPDATE → PD405; DELETE → PD405 unless done by `app_maintenance` on rows older than
12 months (used by retention in M12).
- Only `ORG_UPDATED` is written in M5 (by `update_organization`, `data = {"fields": [...]}`).
- **AUTO-DECIDED:** priest buffer changes and catalog edits are **not** audited (the spec's audit list has no such
  event; adding one is a founder decision).

All three tables: ENABLE + FORCE RLS.

## 2. Policies and grants

| Table | `app_runtime` | `app_domain` |
| --- | --- | --- |
| `samagri_templates`, `samagri_template_items` | SELECT `T` | SELECT/INSERT/UPDATE `T` (+ DELETE on items) |
| `audit_log` | SELECT `T AND current_member_has('AUDIT_READ')` (READ_ONLY, STAFF, PRIEST see nothing) | INSERT `T AND actor_user_id = actor` |
| `offerings` (M2 table) | — | + INSERT `T`, UPDATE `T` (columns `name_hi`, `name_en`, `duration_min`, `suggested_dakshina_paise`, `is_active`) |
| `organizations` (M1) | — | + UPDATE where `id` = tenant and member (columns `name`, `timezone`) |
| `organization_priests` (M1) | — | + UPDATE `T` (columns `default_buffer_before_min`, `default_buffer_after_min`) |

`app_runtime` now gets EXECUTE on `current_member_has` because its `audit_log` policy uses it (spec §04 §7).

## 3. Commands (owner `app_domain`; recipe: permission → idempotency → lock → version → validate → write → audit → finish)

| Function | Permission | Behaviour |
| --- | --- | --- |
| `save_offering(p_offering_id uuid, p_expected_version int, p_fields jsonb, p_idem_key, p_request_hash)` | CATALOG_WRITE | `p_offering_id` NULL = create: from the catalog with `ceremony_type_id` (names and duration default from `ceremony_types`, overridable) or custom (`name_hi`, `name_en`, `duration_min` required). Otherwise update with the version check. Fields: `name_hi`, `name_en` (1–120), `duration_min` (15–1440), `suggested_dakshina_paise` (0–10^11, `null` clears), `is_active`. Unknown fields → PD422; `ceremony_type_id` on update → PD422 `IMMUTABLE_FIELD`. Duplicate English name → 23505 → 409 `DUPLICATE`. |
| `save_samagri_template(p_template_id uuid, p_expected_version int, p_offering_id uuid, p_items jsonb, p_idem_key, p_request_hash)` | CATALOG_WRITE | `p_template_id` NULL = create for `p_offering_id` (must be an offering of the tenant, else PD404 `offering`; a second template for the same offering → 409 `DUPLICATE`). Otherwise replace the items of that template (version check). `p_items`: array of 0–100 `{name, quantity?, provided_by}`; order = array order; invalid → PD422 `details.field = items[i].name` etc. |
| `update_organization(p_expected_version int, p_patch jsonb, p_idem_key, p_request_hash)` | ORG_SETTINGS | patch `name`, `timezone` (IANA only, PD422); writes `ORG_UPDATED` with the changed field names. |
| `update_priest_settings(p_organization_priest_id uuid, p_default_buffer_before_min int, p_default_buffer_after_min int, p_idem_key, p_request_hash)` | ORG_SETTINGS, **or the priest himself** (the link's profile is the actor's own) | NULL = unchanged; 0–240 minutes each (PD422). No If-Match (spec §11 §2). |

Results: offering `{id, ceremony_type_id, name_hi, name_en, duration_min, suggested_dakshina_paise, is_active,
version}`; template `{id, offering_id, version, items: [{position, name, quantity, provided_by}]}`; organization as
`GET /organization`; priest `{id, priest_profile_id, display_name, default_buffer_before_min,
default_buffer_after_min}`; each plus `idempotent_replay`.

## 4. API (shapes AUTO-DECIDED — needs founder review)

| Route | Permission | Notes |
| --- | --- | --- |
| `GET /offerings` | ORG_READ | `{data: Offering[]}` sorted by English name (active first) |
| `POST /offerings` | CATALOG_WRITE | `{ceremony_type_id?, name_hi?, name_en?, duration_min?, suggested_dakshina_paise?, is_active?}`; 201 + ETag |
| `PATCH /offerings/{id}` | CATALOG_WRITE | If-Match; same fields except `ceremony_type_id` |
| `GET /samagri-templates` | ORG_READ | `{data: Template[]}` with items in order |
| `POST /samagri-templates` | CATALOG_WRITE | `{offering_id, items}`; 201 + ETag |
| `PUT /samagri-templates/{id}` | CATALOG_WRITE | If-Match; `{items}` |
| `PATCH /organization` | ORG_SETTINGS | If-Match; `{name?, timezone?}` |
| `PATCH /priests/{organizationPriestId}` | ORG_SETTINGS or self | `{default_buffer_before_min?, default_buffer_after_min?}` |

All writes need `Idempotency-Key`. Money is integer paise in the API; the UI takes rupees and converts with
`parseRupees`.

## 5. Domain (`src/domain/money.ts`, `src/domain/catalog.ts`)

- `Paise` branded integer; `formatPaise(paise)` → `₹1,00,000` / `₹5,100.50` (Indian grouping, Latin digits in both
  languages); `parseRupees("5,100")` → `510000` (accepts `₹`, commas, spaces, up to 2 decimals; rejects negatives,
  floats with 3+ decimals, text, more than ₹1,00,00,00,000) — integer arithmetic only, never floats.
- `isValidDuration(min)` integer 15–1440; `MAX_SAMAGRI_ITEMS = 100`.
- **AUTO-DECIDED:** Latin digits (not Devanagari numerals) in the Hindi UI.

## 6. UI

- Header navigation gains **Settings** (सेटिंग).
- `/settings`: practice name and time zone (ORG_SETTINGS); default travel buffers per priest link (ORG_SETTINGS or
  the priest himself); link to offerings.
- `/settings/offerings`: list (active and inactive); "Add from catalog" (ceremonies not yet offered) and "Add custom".
- `/settings/offerings/{id}`: edit names, duration, suggested dakshina (₹), active; samagri list editor: rows with name,
  quantity, FAMILY/PRIEST toggle, move up/down, remove, add; Save sends POST or PUT with If-Match.
- Without the permission the forms are not shown and the API refuses (403).
